# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **Analysis-not-ready gate** — insight pages (dependency graph, complexity,
  dead code, architecture, impact, AI assistant) now show a friendly live
  progress panel (with current stage and guidance) while a repository is still
  analyzing, instead of a raw `409 Conflict` error. The view unlocks
  automatically when analysis completes. Failed analyses show a re-analyze
  action.

### Changed

- Submitting a repository that is already being analyzed now routes the user
  to that repository's dashboard (to watch live progress) instead of showing
  an error.

### Fixed

- The frontend API client now reads the backend's `{error, message, details}`
  error envelope, so users see the real, human-readable error message instead
  of a bare HTTP status word. `ApiError` exposes `status`, `code`, and
  `details`.

## [0.1.0] — 2026-06-16

Initial public preview. The platform is feature-complete end-to-end across
ten implementation phases.

### Added — Platform

- **Repository ingestion** — submit any public GitHub URL; the worker performs
  a sandboxed shallow clone and persists metadata + commit history.
- **Analysis engine** — multi-language tree-sitter parsing (Python, TS/JS,
  Java, C#, Go), dependency graphs (file / module / service), cyclomatic and
  cognitive complexity, dead-code detection with confidence scoring,
  reverse-impact analysis, layered architecture discovery, Mermaid diagram
  emitter, doc-stub generator.
- **AI engine** — pluggable RAG pipeline with a ChromaDB vector store and
  cited, structured Q&A. LLM provider is selectable via `LLM_PROVIDER`
  (`groq` cloud — default for the free-tier deployment, or `ollama` local);
  embeddings via `EMBEDDING_PROVIDER` (`huggingface`, `local`, or `ollama`).
- **Background jobs** — RQ worker with Tenacity retries, idempotent persist
  phase, structured progress reporter consumed by SSE.
- **Frontend** — React 18 + Vite SPA: dashboard, repository submission form,
  live progress timeline, dependency graph (Cytoscape), complexity heatmaps
  (Recharts), AI chat panel, dark mode.

### Added — Quality

- 60 backend tests, 14 worker tests, 38 frontend tests, 27 OpenAPI contract
  tests; Locust load profile and Playwright E2E flow.
- Strict typing: `mypy --strict` on Python, `tsc --noEmit` on TypeScript.

### Added — Operability

- Layered Docker Compose: base + dev (HMR + volume mounts) + prod (read-only
  rootfs, dropped capabilities, `no-new-privileges`) + observability overlay.
- Prometheus scrape config + recording rules + SLO alert rules.
- Grafana datasource and dashboards (`Backend Overview`,
  `Analysis Pipeline`) provisioned from disk.
- Per-service exporters: redis-exporter, postgres-exporter, node-exporter,
  cadvisor.
- Worker `/metrics` endpoint on port 9101 (jobs in-flight, duration
  histogram, throughput counters, build info).
- Backend Prometheus middleware with request rate, latency histogram, AI
  cache-hit counter.

### Added — DevX & supply chain

- Real CI pipeline: change detection, Python + Frontend lint, six test jobs,
  Docker build matrix (multi-arch), Compose validation, Trivy + Gitleaks
  scans, single aggregated `CI success` gate.
- CodeQL workflow for `python` and `javascript`.
- Release workflow: quality gate → multi-arch image push to GHCR →
  CycloneDX SBOM → autogenerated GitHub Release.

### Documentation

- 18 enterprise documents under `docs/` plus per-phase verification guides.
